DeltaRCM — Module
DeltaRCM

A reduced-complexity river-delta model (Liang et al. 2015) in pure Julia, with the user interface and configuration of pyDeltaRCM.

using DeltaRCM
model = DeltaModel(; Length = 2000, Width = 4000, dx = 50, seed = 0)
run!(model, 50)
model.eta
source
DeltaRCM.DeltaParameters — Type
DeltaParameters

User-facing model configuration. Field names and defaults follow pyDeltaRCM's default.yml exactly, so that existing YAML configuration files work unchanged.

Construct from keywords, a YAML file, or a Dict:

DeltaParameters(; Np_water = 1000, seed = 0)
DeltaParameters("config.yaml"; seed = 1)       # keywords override the file
source
DeltaRCM.DeltaModel — Type
DeltaModel{T}(config; hooks, kwargs...)

A delta model with state at precision T (default Float64; Float32 is accurate to ~1e-5 per step in mass balance and slightly faster; Float16 runs but is not recommended and warns). config may be a DeltaParameters, a path to a pyDeltaRCM-style YAML file, a Dict, or omitted (then everything comes from keywords):

model = DeltaModel(; Length = 2000, Width = 4000, dx = 50, seed = 42)
model = DeltaModel("config.yaml"; Np_water = 500)
step!(model)            # one time step
run!(model, 100)        # 100 time steps
model.eta               # bed elevation, an (L, W) view (first index downstream)

Results are reproducible for a given seed: every parcel draws from its own random stream.

DeltaRCM.step! — Function
step!(model; dt = nothing)

Advance the model one time step: water routing, sediment routing, subsidence, and boundary-condition bookkeeping. Giving dt (seconds) takes a step of that duration instead of the nominal one (sediment volumes, diffusion and subsidence scale with it).

DeltaRCM.run! — Method
run!(model; timesteps, time, time_years, If = 1.0)

Run until a duration has elapsed (exactly one of the keywords): timesteps whole time steps, time model seconds, or time_years real years. time and time_years are scaled by the intermittency factor If (model time = real time × If); any remainder shorter than dt is taken as a final shortened step, so the run ends exactly at the requested time.

DeltaRCM.run_model — Function
run_model(config = nothing; kwargs...)

Configure, run and finalize one model, like pyDeltaRCM's Preprocessor. config is a YAML path or a Dict; keywords add to or override it. Besides the DeltaParameters fields, it accepts the duration keys of run! (timesteps, time, time_years, If), and T (the float type, default Float64). When the configuration has matrix, set or ensemble entries, it is expanded to several jobs (run_jobs). Returns the (finalized) model, or for several jobs the vector of results.

source
DeltaRCM.run_jobs — Function
run_jobs([f,] config; parallel = false, T = Float64, rng) -> Vector

Expand config with expand_jobs and run every job (each also finalized). f(model) is applied to each model after its run, before finalization (e.g. to extract a result); the returned vector holds f's results (the models themselves by default). With parallel = true jobs run as concurrent tasks (each job itself is single-threaded). A table of job parameters is written to jobs_parameters.txt in the root out_dir.

source
DeltaRCM.expand_jobs — Function
expand_jobs(config; rng = Random.default_rng()) -> Vector{Dict{Symbol,Any}}

Expand the matrix (Cartesian product), set (explicit list) and ensemble (replicates with random seeds) entries of a configuration, as pyDeltaRCM's preprocessor does, into one configuration per job. With several jobs, out_dir is required and each job writes to out_dir/job_000, out_dir/job_001, ….

DeltaRCM.HOOK_POINTS — Constant

Points at which a callback f(model) passed as hooks = (; name = f, ...) is called: :init (after construction, before the initial output), :before_step, :before_water, :after_water, :before_sediment, :after_sediment and :after_step (counters advanced, before output is written). These correspond to pyDeltaRCM's hook_* methods. Hooks may read and modify the model's fields, notably the weighting arrays mod_water_weight, mod_sed_weight, mod_erosion and mod_stable_weight (all 1 by default).
