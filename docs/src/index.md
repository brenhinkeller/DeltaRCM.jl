# DeltaRCM.jl

A fast, pure-Julia implementation of the DeltaRCM reduced-complexity river-delta model, with the
configuration and output conventions of pyDeltaRCM. See the [README](https://github.com/brenhinkeller/DeltaRCM.jl)
for an overview, and the pages here for details.
